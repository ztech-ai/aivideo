# 视频制作工具

从仓库根目录运行下方命令。每个文章工程的 `index.html` 挂载六个分镜和一层字幕，`compositions/` 保存成片使用的排版与动画，`assets/` 保存本地媒体、字体和 GSAP。继续剪辑时，直接从这些工程文件开始。

## 查看画面与重渲成片

需要 Python 3.10+、Node.js 22+、FFmpeg、ffprobe 及 Chromium。渲染工具使用 POSIX 文件锁，适用于 Linux 和 macOS。已安装的独立 HyperFrames 技能会使用其官方启动器，其他环境由 npx 获取制作时的 HyperFrames 0.9.94。可用 `HYPERFRAMES_BROWSER_PATH` 指向已安装的浏览器，用 `HYPERFRAMES_RUNNER` 指向已有的 HyperFrames 0.9.94 启动程序。

```bash
python3 制作工具/视频/render.py '20261118什么叫和而不同' --check-only --at 22.5,44.021
python3 制作工具/视频/render.py '20261118什么叫和而不同' --output '../和而不同-复核版.mp4'
```

两条命令都会静态检查工程、运行浏览器布局与对比度检查、开启本机预览，并保存首帧、六个分镜的中点和收尾代表帧。指定的 `--at` 时间会加进抽帧清单。重渲还会检查最终 MP4 的编码、画幅、帧率、音轨以及音画时长。工具会在终端给出预览地址，每次检查的日志和图片存入项目内的 `.hyperframes/artifacts/production/`。省略 `--output` 时，新成片也存入该次日志目录。覆盖指定 MP4 需要显式传入 `--replace`。

| 工程 | 重看人工调整处时可添加的参数 | 需要留意的画面 |
| --- | --- | --- |
| 赚钱的第一性原理 | `--at 5.1,45,50` | 表格、空选框、客户说话与母女餐桌 |
| 管住自己向别人倾诉表白的欲望 | `--at 4.8,23.4,55.1` | 桌前的小禾、上滑录音的手指和结尾捧杯 |
| 什么叫和而不同 | `--at 22.5,44.021` | 院中等花、父女共看手机，字幕位于人物面部上方 |
| 为什么一个人清醒一见人就乱 | `--at 1.4,11,27.5,34.2,50,62` | 筷尖、茶杯、抬眼动作及片尾字幕的右侧空间 |

## 校对字幕

```bash
python3 制作工具/视频/align.py '20261118什么叫和而不同' --out '../和而不同-字幕复核'
```

工具将 `assets/audio/` 下的逐句原录音统一为 16 kHz 单声道，按制作时的间隔拼接后计算 SHA256，随后读取 `ASR/` 内匹配的 MiniMax 逐字时间。每个词的内容及起止时间都保留下来。工具结合 `script.json` 的原稿、`index.html` 的实际音轨入点及《字幕断行.json》的人工分行，生成按原录音计时的 `captions.json` 和按整片计时的《字幕.srt》。四个项目均已离线重建这两份文件，并与定稿逐字节比对。

修改录音后，可提供新的逐字时间 JSON 和匹配的 SHA256，或用 `--transcribe` 调用 `mmx speech transcribe`。在线识别需要 npm 版 mmx CLI 和环境变量 `mmx_api_key`。输出必须是工程外的新目录。烧录字幕的位置和金句整屏展示保存在各片 `compositions/` 内，修改字幕文案或入点时，也需在对应画面层同步更改。

## 导出工程 ZIP

```bash
python3 制作工具/视频/package_projects.py --list 20*/
python3 制作工具/视频/package_projects.py 20*/ -o '../四篇文章短视频项目.zip'
```

也可将 `20*/` 换成一个或多个工程目录。ZIP 包含成片、原文、脚本、分镜、音画素材、字体和可编辑工程。工具会核验文件清单和 CRC。此次四个工程的清单共 216 项，与已交付的 ZIP 一致。

## 初稿编排源档

《创作源档/reconstruct_rough_cut.py》保留了本轮首版编排脚本的六场时间分配、标题模板、分镜动效、引文卡和字幕布局算法。它读取一个已交付工程，将所需素材复制到指定的新目录，在那里重建初版排版。四个项目在首版之后都经过逐镜人工校正，最终字卡高度、字幕位置和插画裁切以各项目当前 HTML 以及《REVIEW.md》为准。只有研究初版或另做版式实验时才需要这个工具。
