# 《我熬了三个月，他没翻一页PPT》制作说明

[播放成片](成片.mp4) · [阅读分场脚本](短视频脚本.md) · [查看观点、论据与引文](创作提炼.md)

本片改编自《赚钱的第一性原理》。原始 DOCX 与带段号的文本存于 `原文/`。正文分析中的 P 编号与文本逐段对应。片中生活故事的原文依据和编剧增写见《创作提炼》。

## 画面与字幕

工程使用 HyperFrames 0.9.94，画幅 1080 × 1920，24 帧／秒。入口为 `index.html`，六个分镜、引文画面和字幕层位于 `compositions/`。插画在 `assets/art/`，中文字幕使用随工程打包的简体中文字形。外部播放器可使用《字幕.srt》；MP4 本身已有画面字幕。

## 声音

- 出镜声部为首单客户、方案人、旁白、新客户。旁白与角色对白由 MiniMax 官方 `mmx speech synthesize` 调用 `speech-2.8-hd` 分句生成；`assets/audio/` 留存逐句 MP3，`assets/mix/` 是剪辑所用的响度均衡 WAV。
- MiniMax Music 2.6 与 3.0 对当前账户返回 HTTP 410。此片配乐《散会以后》由 `mmx text chat` 调用 MiniMax-M3 写成可演奏乐谱，速度 76 拍／分，再用 FluidSynth 与 TimGM6mb 音色库演奏。乐谱保存在 `assets/audio/score.json`，音轨为 `assets/audio/music.mp3`。
- 中文字幕以 `mmx speech transcribe` 返回的逐字时间与原稿校对。原声相对时码在 `captions.json`，全片时码在《字幕.srt》。

## 继续剪辑

在本目录执行 `npm run dev`，可在 HyperFrames 编辑器预览。修改镜头或对白时，可在时间线上调整分镜、字幕以及独立音轨。执行 `npm run render` 会以 24 帧／秒重新输出成片。重新渲染使用本地已有媒体，需可用的 HyperFrames、Chromium 与 FFmpeg。
